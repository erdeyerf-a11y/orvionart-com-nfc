# ORVIONART 0.10.58 — Basit Süper Admin akışı

1. Süper Admin'e giriş yap.
2. Deneyimler bölümünden yeni deneyim oluştur; başlık ve açıklamayı yazıp taslak kaydet.
3. Deneyim ekranındaki medya kısayolundan fotoğraf/video ekle.
4. Deneyimi yayımla. Taslak veya arşiv içerik ziyaretçilere açılmaz.
5. Aynı deneyim ekranındaki QR/NFC bölümünden bağlantı oluştur.
6. QR SVG dosyasını indir; NFC etiketi için aynı kalıcı URL'yi kopyala. NFC fiziksel yazımı ayrı bir telefon uygulaması/cihazla yapılır.
7. Gerçek HTTPS sunucusunda QR'yi telefonla okut; doğru içeriğin açıldığını doğrula. İçerik başlığı/slug değişince aynı QR'yi tekrar test et.

Bu belge kaynak kodundaki tasarlanmış akışı anlatır. Gerçek sunucu/telefon testi yapılmadan “çalışıyor” kabul edilmez.
